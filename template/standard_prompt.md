# ParableHeart 标准生成指令

将以下内容发送给任何大模型（GPT、Claude、豆包等），即可稳定产出符合质量标准的情感心理学寓言。

---

请按照以下严格格式，创作一篇情感心理学寓言。

【格式要求】
1. 寓言标题：有画面感、有诗意，不要直接出现心理学概念
2. 寓言故事：800-1200字，有人物、有情节、有结局、有余味
3. 概念揭示：明确指出这个故事对应的心理学概念，给出学术定义
4. 映射表：列出故事要素与概念要素的一一对应关系（表格形式）
5. 通俗解释：用大白话把这个概念讲清楚，200字左右
6. 现实应用：至少3个真实场景的应用案例
7. 自测问题：设计一个能让读者代入思考的情境问题

【创作原则】
- 人物要普通：守钟人、园丁、画师、磨镜人……不要用王子公主
- 结局要遗憾但不绝望：错过、醒悟、后知后觉……这才是真实的人生
- 概念要准确：必须是真正的心理学概念，不是鸡汤
- 语气要克制：不说教、不评判、不站在道德高地，只是讲故事
- 余味要足：最后留一句能让人心里咯噔一下的话

【已创作过的概念（不要重复）】
- 无条件积极关注
- 情感拖延
- 自我完善陷阱
- 关系分析瘫痪
- 理想化偏误与具体化接纳
