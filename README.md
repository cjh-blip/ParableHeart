# ParableHeart

▎ 我们学了太多情感心理学概念，
▎ 但记住的往往不是定义，
▎ 而是故事里那个守钟人、那个园丁、那个画师。
▎
▎ ParableHeart 试图做一件事：
▎ 把心理学论文里的抽象概念，
▎ 变成你读完会心里咯噔一下的故事。

---

## 项目定位

ParableHeart 是一个情感心理学寓言项目。我们不教套路，只讲人心——每个故事都是一面镜子，让读者看见自己在亲密关系中的模样。

核心价值：
- **有画面感**：用普通人的故事承载抽象概念
- **有学术支撑**：每个故事对应真正的心理学概念
- **有现实应用**：不只是读故事，更能在生活中用得上

## 如何参与

这个项目欢迎所有人贡献新故事。创作方式很简单：

1. 选择一个未被创作过的心理学概念（参考 [概念地图](./concepts/concept_map.md)）
2. 使用我们的 [标准生成模板](./template/standard_prompt.md) 生成故事
3. 提交 Pull Request

### 创作原则

- **人物要普通**：守钟人、园丁、画师、磨镜人……不要用王子公主
- **结局要遗憾但不绝望**：错过、醒悟、后知后觉……这才是真实的人生
- **概念要准确**：必须是真正的心理学概念，不是鸡汤
- **语气要克制**：不说教、不评判、不站在道德高地，只是讲故事
- **余味要足**：最后留一句能让人心里咯噔一下的话

## 创作模板

完整的生成指令已放在 [template/standard_prompt.md](./template/standard_prompt.md)，直接复制给任何大模型（GPT、Claude、豆包等）即可使用。

每篇故事包含：
1. 寓言标题
2. 寓言故事（800-1200字）
3. 概念揭示（学术定义）
4. 映射表（故事与概念的对应关系）
5. 通俗解释（200字左右）
6. 现实应用（至少3个真实场景）
7. 自测问题（让读者代入思考的情境）
