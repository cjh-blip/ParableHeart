# ParableHeart 概念地图

## 概念总览

| 序号 | 概念名称 | 核心理论来源 | 一句话概括 |
|------|----------|--------------|------------|
| 001 | 无条件积极关注 | 人本主义心理学（卡尔·罗杰斯） | 接纳对方本来的样子去爱，而非将爱建立在对方符合期待的条件之上 |
| 002 | 情感拖延 | 成人依恋理论 | 面对关系升级、情感表达时反复推迟行动，回避不确定性与被拒绝风险 |
| 003 | 自我完善陷阱 | 亲密关系认知偏差 | 以“我必须先成为足够好的人”为借口，回避关系中的脆弱暴露和情感风险 |
| 004 | 关系分析瘫痪 | 亲密关系认知过程 | 过度依赖逻辑推演和风险分析以求“最优解”，在持续分析中丧失行动时机 |
| 005 | 理想化偏误与具体化接纳 | 亲密关系认知 | 用心中完美伴侣的抽象模板衡量现实，而非在具体互动中接纳真实的对方 |
| 006 | 共情与同情的区别 | 情感回应理论 | 同情是“镜像”式的情绪融合，共情是“同频”式的陪伴与理解 |
| 007 | 情感验证 | 亲密关系修复 | 不加评判地承认对方情绪的合理性，用在场传递“你的感受可以被接住” |
| 008 | 双向投入对等性 | 关系承诺理论 | 关系稳定不只取决于各自付出多少，而取决于双方是否都感知到对方愿意为自己调整 |
| 009 | 元沟通 | 沟通理论 | 关于沟通的沟通，跳出争议内容、转向对沟通模式进行检视和纠偏 |
| 010 | 单向亲密 | 情感不对等 | 一方长期分享靠近，另一方只倾听但不暴露脆弱，维持“看起来像亲密”的形态 |
| 011 | 回避型依恋 | 依恋理论 | 习惯性压抑情感需求、回避亲密接触，以保护自己免受期待落空与情感受伤 |
| 012 | 分化 | 家庭系统理论 | 在保持情感联结的同时，发展并坚持独立的自我，做到“我与你不同，但我仍然爱你” |

## 新增概念流程

1. 确认是真正的心理学概念，有学术出处和定义
2. 检查未被创作过
3. 使用标准 prompt 生成故事
4. 更新本表增加新概念
5. 更新 README.md 故事目录
